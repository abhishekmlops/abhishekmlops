## Build Philosophy

Four rules I don't negotiate on.

- **Prove it before you use it.** Every data structure is hand-built before a library is touched.
- **Complexity is non-optional.** Every function ships with explicit time + space analysis. No exceptions.
- **Source first.** CLRS alongside LeetCode. Theory and implementation, in the correct order.
- **Production habits from day one.** PEP8, docstrings, edge cases — because bad habits compound.
